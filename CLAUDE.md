# PSY Boost — Контекст проекта

## Описание

**PSY Boost** — SaaS-платформа для маркетинговой упаковки психологов на основе JTBD-фреймворка. Помогает психологам структурировать услуги, создавать продуктовую линейку и генерировать маркетинговые материалы с помощью ИИ.

## Стек технологий

| Слой | Технологии |
|------|-----------|
| Frontend | React 18, TypeScript, CSS Modules, Vite |
| Backend | Node.js, Express, TypeScript |
| База данных | PostgreSQL (основная), Redis (кэш / очереди) |
| Аутентификация | JWT (access + refresh tokens), Google OAuth 2.0 |
| Очереди | Bull (Redis-based) — для AI-задач |

## Основные модули

1. **Чат-упаковка по JTBD** — диалоговый интерфейс для выявления Jobs To Be Done клиентов психолога
2. **Продукты КПТ** — конструктор трёхуровневой продуктовой линейки:
   - Лид-магнит (бесплатный входной продукт)
   - Мини-продукт (недорогой платный)
   - Основной продукт (флагманская программа)
3. **Генерация текстов** — AI-генерация маркетинговых материалов (посты, лендинги, описания услуг)
4. **Целевая аудитория / Проекты** — управление аватарами ЦА и проектами психолога
5. **Обучение** — образовательные материалы по JTBD и упаковке
6. **Тарифы и оплата** — подписочная модель, управление тарифными планами

## ИИ-интеграции

- **OpenAI (ChatGPT)** — `openai` npm package
- **Google Gemini** — `@google/generative-ai`
- **Anthropic Claude** — `@anthropic-ai/sdk`
- **Grok (xAI)** — xAI API
- **Nano Banana Pro** — кастомная интеграция

## Структура директорий

```
/psy-boost
  /frontend
    /src
      /components    — переиспользуемые UI-компоненты
      /pages         — страницы приложения
      /hooks         — кастомные React-хуки
      /api           — клиент для запросов к backend (axios)
      /store         — глобальное состояние (zustand)
      /styles        — глобальные CSS-переменные и сбросы
      /types         — TypeScript-типы и интерфейсы
  /backend
    /src
      /routes        — Express-роутеры
      /controllers   — обработчики запросов
      /services      — бизнес-логика
      /models        — модели и запросы к БД
      /middleware    — auth, validation, error handling
      /utils         — вспомогательные функции
  /docs              — документация API и архитектуры
```

## Соглашения

- API эндпоинты: `/api/v1/...`
- Переменные окружения: `.env` (не коммитить, есть `.env.example`)
- Все тексты интерфейса — на русском языке
- Backend порт: `3001`, Frontend dev-сервер: `5173`
