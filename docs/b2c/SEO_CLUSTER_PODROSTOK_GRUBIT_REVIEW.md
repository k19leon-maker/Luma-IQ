## Внешняя экспертная проверка

Внешняя проверка практикующим психологом не имитируется и не отмечается выполненной. До неё:

- на страницах не показывается имя рецензента;
- не используется формулировка `проверено психологом`;
- автором остаётся `Редакция Luma IQ`.

Для завершения внешней проверки психолог должен подтвердить:

1. корректность описания подростковой сепарации и семейной динамики;
2. безопасность предложенных фраз и последствий;
3. полноту кризисных оговорок;
4. отсутствие скрытой диагностики;
5. допустимость материалов для публичной публикации.

После фактической проверки в данные статьи можно добавить `reviewer` с реальным именем, квалификацией и датой проверки.
