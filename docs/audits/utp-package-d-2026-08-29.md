# УТП — пакет D — двухколоночная рабочая область

Дата: 2026-08-29

Статус: завершён

## Реализовано

- Старый монолитный экран с inline-стилями заменён на локальную компонентную
  рабочую область.
- На desktop используется grid 38/62: слева «Основа для УТП», справа визуально
  главный редактор «Ваше УТП».
- Левая колонка читает owner-checked `UtpFoundation v1` и показывает нишу,
  аудиторию, JTBD, 3–6 болей и желаемый результат.
- Длинные значения сворачиваются и раскрываются командой «Показать полностью».
- Missing и ambiguous состояния не маскируются выдуманным текстом; ссылки
  «Заполнить», «Выбрать» и «Изменить» ведут только на безопасные внутренние
  `/app/` маршруты.
- Правая колонка содержит один связный textarea, основные AI-действия,
  копирование, missing-data рекомендации и компактную историю версий.
- AI-доработка вынесена в отдельную панель с быстрыми командами и существующим
  `VoiceComposer`.
- Справка о семи компонентах УТП вынесена в компактный popover. Он доступен с
  клавиатуры и закрывается по `Escape`, кнопке или клику снаружи.
- На ширине до 980 px колонки переходят в последовательный поток foundation →
  editor; на mobile кнопки и история переходят в одну колонку без горизонтального
  скролла.

## Компонентная структура

- `UTP.tsx` — page container, foundation fetch и существующие AI handlers.
- `UtpFoundationPanel.tsx` — read-only контекст текущего проекта.
- `UtpEditorPanel.tsx` — главный textarea, действия, история и missing data.
- `UtpHelpPopover.tsx` — справка о внутренней структуре УТП.
- `UtpMissingData.tsx` — рекомендации и безопасные внутренние переходы.
- `UtpAiImprovePanel.tsx` — команды и голосовая инструкция для AI-доработки.
- `UTP.module.css` — весь layout, states и responsive без inline styles.

## Границы пакета

- AI-контракт, billing, хранение и глобальная навигация не менялись.
- Autosave ручного текста, защита от race при смене проекта и current/proposed
  подтверждение относятся к следующим пакетам E–F.
- Production-данные не изменялись, деплой не выполнялся.

## Проверки

- 38 целевых unit/contract тестов прошли.
- Frontend production build прошёл.
- Backend TypeScript build прошёл.
- ESLint для всех новых компонентов УТП прошёл без замечаний.
- Полный backend regression: 439 тестов прошли, 1 пропущен.
- Осталась 1 ранее известная, не связанная с УТП ошибка provider-boundary:
  `controllers/semeyno-ai-relay.controller.ts` содержит прямой URL OpenAI.
- Локальный browser smoke дошёл до штатного auth redirect. Визуальная проверка
  авторизованной рабочей области невозможна без пользовательской сессии; обход
  авторизации не применялся.

## Итог

Пакет D закрыт. Раздел имеет целевую двухколоночную структуру и адаптивный
одноколоночный режим. Следующий этап — пакет E: редактор, autosave и сохранность
данных при смене проекта.
