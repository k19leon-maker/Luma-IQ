# ТГ-канал: пакет F — workspace контент-плана

Дата: 24 августа 2026 года.

## Результат

- Табличный экран заменён на list/detail workspace.
- Список показывает номер, роль, тему и статус каждой идеи.
- Идея редактируется вручную по полям: роль, задача читателя, тема, ключевая
  мысль и CTA.
- Черновик, готовый и запланированный пост открываются в отдельной рабочей
  области с полным редактируемым текстом.
- Ручные правки сохраняются при переключении между постами.
- Добавлены создание идеи, удаление с подтверждением, копирование,
  «В Контент-план» и контекстное меню.
- Массовая генерация сохранена как вторичное действие в меню.
- На tablet/mobile реализован маршрут список → деталь → «К плану».

## Контракт данных

- В rollback mirror и v2-плане сохраняется `keyMessage`.
- Статус ручного черновика `draft` больше не превращается в `ready` при
  сериализации и повторной загрузке.
- Добавление, замена и удаление элементов вынесены в чистые функции и покрыты
  unit-тестами.

## Проверки

- Target Vitest: 6 файлов, 24 теста — успешно.
- Frontend type-check и target ESLint — успешно.
- Backend build и target ESLint — успешно.
- `git diff --check` — успешно.
- Browser QA: 1440×900, 1024×768, 768×1024, 390×844 и 360×800 — успешно.
- Проверены ручное редактирование с переключением, добавление идеи, удаление с
  подтверждением и четыре статуса поста.
- Во всех проверенных viewport `scrollWidth === innerWidth`.
- Browser errors отсутствуют; есть только штатные предупреждения React Router
  о будущих флагах v7.
- Полный backend suite: 355 тестов прошли, 1 пропущен; один ранее
  существовавший `provider-boundary.test.ts` падает из-за прямого OpenAI URL в
  `semeyno-ai-relay.controller.ts`. Этот модуль пакет F не изменяет.
