# Этап 11. Пользовательский UX и три публичных тарифа

Дата завершения: 2026-07-26.

## Публичные тарифы

Новые покупки доступны только для трёх самостоятельных тарифов:

- Start;
- Pro;
- Expert.

Тарифы Support, Marketing Partner и Implementation остаются в backend-конфигурации, существующих subscriptions, payments и админке. Они скрыты только из публичного каталога и не удаляются из базы.

Ручная миграция пользователя выполняется существующим admin endpoint изменения доступа. Операция:

- обновляет subscription;
- не удаляет историю платежей;
- при указанной оплате создаёт отдельный payment;
- пишет `admin_access_updated` в user events.

## AI-баланс и стоимость

- Workflow quote получает активную versioned action price с backend.
- Quote возвращает стоимость, доступный остаток и остаток после действия.
- Компоненты стоимости обновляются после успешного AI-действия.
- При недостаточном балансе V2 reservation завершается ошибкой до provider execution.
- Ошибка генерации сообщает, что баллы не списаны или возвращены.
- Полная сборка и AI-доработка продукта отображаются как разные действия с разной ценой.
- Страница «Лимиты» получает action prices из `/billing/me`, а не из статического frontend-конфига.

## Безопасный пользовательский API

Пользовательские billing endpoints больше не возвращают:

- внутренний AI budget в рублях;
- токены;
- provider cost;
- реальные model IDs;
- legacy-тарифы сопровождения в публичном каталоге.

В ответе остаются тариф, AI-баланс, проекты, дата обновления, история и публичные цены AI-действий.

## Выбор моделей
